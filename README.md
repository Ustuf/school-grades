# Оценки учеников

Одностраничный сайт с входом по почте и паролю (Supabase Auth, `supabase-js` через CDN).

- **Родитель** видит только своих детей: предметы, учителей, оценки и даты.
- **Учитель** видит учеников по классам, где он ведёт предмет, и может менять оценки по своему предмету.
- **Ученик** видит свои предметы, их учителей, оценки и даты.
- Ученики могут зарегистрироваться сами, выбрав класс. Родителей и учителей добавляет администратор.

## Запуск

Открыть `index.html` или запустить локальный сервер (http://localhost:3000):

```bash
node server.js
```

## База данных

Один раз выполнить в Supabase (SQL Editor) `auth_roles.sql` (таблицы `profiles` и `teaching`, функции доступа, регистрация учеников), затем `rls_policies.sql` (политики RLS и права на колонки). Сайт читает данные через функции, а прямые запросы к таблицам ограничены политиками RLS.

В `index.html` используется публичный (publishable) ключ Supabase. Секретные ключи в репозиторий не попадают.

Чтобы работала саморегистрация, в Supabase (Authentication → Sign In / Providers) должна быть включена регистрация, а для мгновенного входа после неё отключено подтверждение почты.
- **Тестовые пользователи** (`test_users.sql`) в репозиторий не входят: пароль там простой, их нужно удалить после демонстрации.
