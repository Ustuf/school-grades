# Оценки учеников

Одностраничный сайт: список учеников, класс, предмет, оценка и дата. Данные берутся из Supabase (`supabase-js` подключён через CDN). Менять на сайте можно только оценку (2–5).

## Запуск

Открыть `index.html` или запустить локальный сервер:

```bash
node server.js
```

Адрес: http://localhost:3000

## База данных

Один раз выполнить `public_access.sql` в Supabase (SQL Editor). Он создаёт представление `grades_public` (ФИО, класс, предмет, оценка, дата) и функцию `set_grade`, которая меняет только оценку.

В `index.html` используется публичный (publishable) ключ Supabase. Секретные ключи в репозиторий не попадают.
